# استعادة محرر الأسهم والأيقونات

النسخة المحفوظة موجودة في جذر المشروع باسم:

`layout-editor-backup-20260825.zip`

تحتوي النسخة على مكوّن المحرر، ربطه بفرعي أبها وخميس مشيط، واجهات الحفظ، ملفات المواضع، والأنماط اللازمة.

## الاستعادة السريعة

1. فك محتوى الملف المضغوط فوق جذر المشروع مع السماح باستبدال الملفات.
2. شغّل `npm run typecheck`.
3. شغّل `npm run build`.

لا تُحذف بيانات المواضع الحالية عند تعطيل المحرر، لذلك تعود الأسهم والأيقونات في مواضعها المحفوظة بعد الاستعادة.
